# SPI Assignment

This project implements an SPI slave in SystemVerilog and verifies it with a testbench and memory model.

## Included Files

- `spi_slave.sv` for the SPI slave logic
- `spi_memory.sv` for the memory/register-map model
- `spi_tb.sv` for simulation and verification
- `spi_types_pkg.sv` for shared types and enums
- `run.do` and `wave.do` for simulation setup
- `SPI_documentation.pdf` for the assignment reference

## Summary

The design supports SPI communication with read and write transactions and is intended to be simulated in a HDL simulation flow.
