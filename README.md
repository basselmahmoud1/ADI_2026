# ADI Summer Intern 2026

This repository contains assignment work for the ADI Summer Intern 2026 program.

## Main Content

- `Eng.Fatma_Ali_assingnments/FPGA/` includes FPGA design projects, Vivado files, reports, and supporting images.
- `Eng.Fatma_Ali_assingnments/SPI/` includes the SPI slave assignment, testbench, memory model, shared package, and documentation.

## SPI Project

The SPI folder contains a SystemVerilog implementation of an SPI slave connected to a memory model and validated with a testbench.
